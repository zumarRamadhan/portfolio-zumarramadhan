# 🚀 Zumar Ramadhan — Personal Portfolio Website

Website portofolio profesional yang modern, responsif, dan interaktif untuk menampilkan keahlian dan proyek di bidang **UI/UX Design**, **Front-End Web Development**, **Visual Branding**, dan **Social Media Management**.

---

## ✨ Fitur Utama

- 🎨 **Interactive Design Workflow:** Menampilkan alur kerja sistematis dari riset *brief*, desain UI/UX di Figma, implementasi *Front-End*, hingga tahap *deploy*.
- 📂 **Dynamic Portfolio Filter:** Sistem filter proyek interaktif berdasarkan kategori (UI/UX Design, Front-End Dev, Branding, & Social Media).
- 📱 **Fully Responsive Layout:** Dirancang dengan prinsip *mobile-first* menggunakan Tailwind CSS agar tampil sempurna di berbagai ukuran layar.
- ⬆️ **Scroll to Top Feature:** Tombol navigasi otomatis yang muncul saat menggulir ke bawah untuk kenyamanan pengguna.
- 💬 **Direct Contact Integration:** Akses cepat langsung terhubung ke email dan WhatsApp.

---

## 🛠️ Tech Stack

Proyek ini dibangun menggunakan teknologi modern tanpa *framework* yang berat agar performanya cepat dan ringan:

- **Markup & Styling:** HTML5, Tailwind CSS
- **Interactivity:** Vanilla JavaScript (ES6+)
- **Design & Prototyping:** Figma
- **Deployment:** GitHub Pages
